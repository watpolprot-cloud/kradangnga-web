# เว็บไซต์คณะสีกระดังงา (สีเขียว) · โรงเรียนพรตพิทยพยัต

เว็บของครูและนักเรียนคณะสีกระดังงา รวมข่าวสาร ภาพกิจกรรม ความทรงจำ ทำเนียบครู เวรประจำจุดของครู ทำเนียบนักเรียน และข้อมูลบุนนาคเกมส์ 2569

- เป็นเว็บแบบไฟล์ล้วน (HTML/CSS/JS) ไม่ต้องติดตั้งอะไร เปิด `index.html` ได้ทันที
- ข้อมูลทั้งหมดอยู่ใน `data/*.js` แก้ไขแล้วเว็บเปลี่ยนตาม
- ภาพอยู่ใน `assets/img/` (gallery = ภาพใหญ่, thumbs = ภาพย่อ)
- ฟอนต์ Prompt, Sarabun, Charmonman ใช้ภายใต้สัญญาอนุญาต SIL Open Font License (`assets/fonts/`)

## คลิป TikTok (หน้า tiktok.html)

- GitHub Actions (`.github/workflows/tiktok-sync.yml`) รัน `tools/tiktok_sync.py` วันละ 2 ครั้ง (06.00 และ 18.00 น.) ดึงคลิปจาก TikTok @kradangnga.prot มาไว้ที่ `data/tiktok-feed.js` และภาพปกที่ `assets/img/tiktok/` แล้วบันทึกขึ้นเว็บเอง ไม่ต้องแก้สองที่นี้ด้วยมือ
- อยากดึงทันที: แท็บ Actions > ดึงคลิป TikTok > Run workflow
- ตั้งหมวด คำที่ใช้จัดหมวด ชื่อเรื่องและคำอธิบายรายคลิป หรือซ่อนคลิป แก้ที่ `data/tiktok.js`
- ส่วน "หน้า TikTok ของคณะสี" ใช้ตัวฝังของ TikTok เอง คลิปใหม่ขึ้นทันทีที่โพสต์
- เพราะ Actions บันทึกไฟล์ขึ้น GitHub เอง ก่อนกด Commit ใน GitHub Desktop ให้กด Fetch/Pull origin ก่อนทุกครั้ง

## โพสต์ Instagram และแถบประกาศด่วน (หน้า instagram.html)

- GitHub Actions (`.github/workflows/instagram-sync.yml`) รัน `tools/instagram_sync.py` ทุก 2 ชั่วโมง (06.15–22.15 น.) ดึงโพสต์จาก Instagram @green.prot มาไว้ที่ `data/instagram-feed.js` และภาพที่ `assets/img/instagram/` แล้วบันทึกขึ้นเว็บเอง ไม่ต้องแก้สองที่นี้ด้วยมือ
- Instagram ให้ดึงแบบไม่ล็อกอินได้ครั้งละ 6 โพสต์ล่าสุด บอทจึงเก็บโพสต์สะสมไว้เรื่อย ๆ โพสต์เก่ากว่านั้นถ้าอยากให้ขึ้นเว็บ ใส่รหัสโพสต์ใน `posts` ของ `data/instagram.js` แล้วบอทจะไปดึงมาให้
- ตั้งหมวด ชื่อเรื่องและคำอธิบายรายโพสต์ ปักหมุดประกาศด่วน หรือซ่อนโพสต์ แก้ที่ `data/instagram.js`
- ประกาศด่วน: โพสต์ที่มีคำใน `urgent.words` (เช่น ด่วน เลื่อน ยกเลิก งดซ้อม) ภายใน 3 วัน หรือโพสต์ที่ใส่ `urgent: true` จะขึ้นแถบสีทองใต้เมนูทุกหน้า ผู้ชมกดปิดได้
- ประกาศแบบประกาศในกลุ่ม LINE: โพสต์ที่ใส่ `pin: true` (และ `until` วันที่ให้หายเอง) ขึ้นแถบ "ประกาศ" ไอคอนโทรโข่งใต้เมนูทุกหน้า กดลูกศรอ่านรายละเอียดจาก `note` กด "ดูประกาศ" เปิดโพสต์ และกด × ปิดได้ (เว็บจำไว้ในเครื่องผู้ชม ไม่ขึ้นซ้ำ)
- โพสต์เรื่องเงินและโพสต์ที่ในภาพมี QR code ไม่ขึ้นเว็บ (บอทตรวจ QR ในภาพเอง) ถ้าแน่ใจว่าโพสต์นั้นขึ้นได้ ใส่ `show: true`
- อยากดึงทันที: แท็บ Actions > ดึงโพสต์ Instagram > Run workflow

## เวรประจำจุดของครู (หน้า duty.html)

- ข้อมูลอยู่ที่ `data/duty.js` แต่ละช่วงเวรมี เลขจุด บริเวณ เวลา ช่วง (เช้า/กลางวัน/บ่าย) และชื่อครู ชื่อครูต้องตรงกับ `data/teachers.js` รูปครูดึงจากทำเนียบครูให้เอง ช่วงที่ยังไม่มีครูลงเวรให้เว้นเป็น `[]` ครูที่ยังไม่อยู่ในทำเนียบครู (เช่น ครูใหม่ที่ยังไม่มีรูป) หน้าเวรจะแสดงตราโรงเรียนในวงกลมแทนรูป
- ทำเนียบครูแสดงบรรทัด "เวร: จุดที่ ..." ใต้ชื่อครูจากไฟล์เดียวกัน กดแล้วไปหน้าเวรที่เลือกชื่อครูไว้ให้ (`duty.html?t=ชื่อครู`)
- ภาพเวรสำหรับส่งกลุ่ม LINE อยู่ที่ `assets/img/duty/` (ภาพย่อลงท้าย `-s.jpg`) รายชื่อไฟล์อยู่ใน `KD.dutyMeta.images`
- ขึ้นภาคเรียนใหม่ ให้แก้ `data/duty.js` เปลี่ยนภาพใน `assets/img/duty/` และเพิ่มข่าวใน `data/news.js`

## แชตบอต "น้องกระดังงา" (ปุ่มมุมขวาล่างของทุกหน้า)

- หน้าต่างแชตอยู่ที่ `js/chatbot.js` และ CSS ส่วน "แชตบอต" ใน `css/style.css` โดย `js/common.js` โหลดให้ทุกหน้าเอง
- ชื่อบอต คำทักทาย ปุ่มคำถามตัวอย่าง กติกาการตอบ (`rules`) และรุ่น Gemini ที่ใช้ แก้ที่ `data/chatbot.js`
- ความรู้ของบอต: GitHub Actions (`.github/workflows/chatbot-knowledge.yml`) รัน `tools/build_chatbot.js` รวมข่าว ทำเนียบ กติกาบุนนาคเกมส์ อัลบั้ม คลิป TikTok โพสต์ Instagram และข้อความทุกหน้า ไว้ที่ `data/chatbot-knowledge.json` ทุกครั้งที่แก้ข้อมูลหรือหลังบอท TikTok/Instagram ดึงของใหม่ ไม่ต้องแก้ไฟล์นี้ด้วยมือ
- คำถามส่งไปที่ตัวกลางใน Google Apps Script ของครูนพพล (ลิงก์ Web app ใส่ที่ `endpoint` ใน `data/chatbot.js`) ตัวกลางเก็บ Gemini API key ไว้ในพร็อพเพอร์ตีของสคริปต์ชื่อ `GEMINI_API_KEY` แล้วถาม Gemini พร้อมความรู้จากเว็บ ต้นฉบับโค้ดตัวกลางอยู่ที่ `tools/chatbot_proxy.gs`
- ห้ามใส่ API key ในไฟล์ใดของเว็บหรือ repo เพราะใครก็เปิดดูได้ ถ้าต้องเปลี่ยน key ให้แก้ค่า `GEMINI_API_KEY` ในโปรเจกต์ Apps Script (ไม่ต้อง Deploy ใหม่)
- ตัวกลางจำกัดวันละ 1,500 คำถามกันโควตาฟรีหมด ถ้าเกินหรือต่อไม่ได้ บอตจะค้นหาเรื่องในเว็บให้แทน
- แก้โค้ดตัวกลางแล้วต้องกด Deploy > Manage deployments > แก้ไข > เวอร์ชันใหม่ ลิงก์เดิมจึงจะใช้โค้ดใหม่
